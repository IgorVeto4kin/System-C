# Первое задание: Добавление системного вызова и вызова SBI для чтения регистра MISA

## Описание решения
В рамках задания я пытался реализовать сквозной вызов от U-Mode (приложение) до M-Mode (OpenSBI). Вместо чтения банального регистра (типа mvendorid), реализовано чтение регистра **MISA** (Machine ISA). Пользовательское приложение не просто получает число, а парсит битовую маску регистра и выводит на экран поддерживаемые процессором аппаратные расширения (I, M, A, F, D, C и т.д.) и разрядность архитектуры.

В папках kernel и openSBI лежат исправления, которые внесены в исходники, полный код исходников - в папке linux7.0.9 и opensbi
